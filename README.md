# Arcade Vault

Es una plataforma para jugar online y competir por la mayor cantidad de puntos.

## Desarrollo

Usa **Spec Driven Design**, basado en `/spec` y `/spec-impl`.

Sigue las buenas prácticas recomendadas en [Fernando Skills](https://github.com/Klerith/fernando-skills).

## Skills usadas

```bash
npx skills@latest add Klerith/fernando-skills
```

## Comandos

Gestor de paquetes: **bun** (`bun.lock`).

- `bun dev` — servidor de desarrollo (`next dev`)
- `bun run build` — build de producción
- `bun start` — sirve el build
- `bun run lint` — ESLint (flat config, `eslint.config.mjs`)

No hay framework de tests configurado todavía.
